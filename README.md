# Proyecto Final Control Estadístico de Procesos

El presente repositorio contiene una simulación del proceso de llenado de latas de gaseosa.
Para poder visualizarlo es necesario descargar el archivo html (se llama simulacion_linea_llenado_latas).
- En la animación se cuentan con los botones de **Iniciar proceso**, **Pausar** y **Reiniciar**, los cuales se encuentran hasta abajo.
- La lata vacía pasa por el proceso de llenado, verificación y clasificación.
- En el área de verificación se pesa a la lata con la soda y si se encuentra dentro de los límites de especificación, se continúa para el proceso de empaque. En caso contrario, la lata pasa a reprocesarse.
